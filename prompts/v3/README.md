# Prompt v3 (post-freeze)

Prompt v3 is an additive, post-freeze candidate prompted by the retail_sales pilot. Cleaning and
analysis retain the v2 requirements. Reporting now exposes non-answer contract metadata that v2
kept validator-only: which findings require direction/ranking and the exact metric-key-to-label
mapping. The active workflow remains v2 until a separately approved experiment adopts v3.
