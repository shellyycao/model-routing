Cleaning logic reported by the cleaning stage:
R1: All columns read as text; every cell is stripped of whitespace; empty string, 'NA', 'N/A', 'null', 'None', and '-' (case-insensitive) are replaced with NaN. R2: Duplicate reading_id rows are removed before any other filter, keeping only the first occurrence. R3: reading_date is parsed by trying five explicit date formats in order (YYYY-MM-DD, MM/DD/YYYY, DD-Mon-YYYY, YYYY/MM/DD, 'Month D, YYYY'); rows with missing or unparseable dates are dropped; dates are written as YYYY-MM-DD. R5: building_type is mapped case-insensitively to Residential/Commercial/Industrial (including short variants Res, Resi, Comm, Ind); unrecognised or missing values cause the row to be dropped. R6: tariff is mapped case-insensitively to 'peak' or 'off-peak' (accepting 'offpeak' and 'off peak'); rows with missing or unrecognised tariff are dropped. R7: energy values have commas removed; MWh suffix triggers multiplication by 1000; kWh suffix is stripped; bare numbers are treated as kWh; the column is renamed energy_kwh; rows that are missing, non-numeric, negative, or above 100 000 kWh are dropped; values are rounded to 2 decimal places. R8: temperature values have degree signs and unit letters stripped; Fahrenheit values (ending F/°F) are converted to Celsius; the column is renamed temperature_c and rounded to 1 decimal; values outside -40 to 50 °C (or unparseable) are set to NaN but the row is kept. R9: Output contains exactly the seven required columns in the specified order, sorted by reading_id ascending, written as a CSV with a header and no index; missing temperature_c appears as an empty cell.

## Analysis questions and the metric_keys each must produce
- q1: Overall (aggregation): sum of energy_kwh -> total_kwh; number of readings (rows) -> reading_count; total_kwh / reading_count -> mean_kwh_per_reading.
  metric_keys: total_kwh, reading_count, mean_kwh_per_reading
- q2: Building types (group comparison): total energy_kwh per building_type -> kwh_residential, kwh_commercial, kwh_industrial.
  metric_keys: kwh_residential, kwh_commercial, kwh_industrial
- q3: Quarterly trend (trend): total energy_kwh of readings dated in each calendar quarter of 2024 (Q1 = Jan-Mar, Q2 = Apr-Jun, Q3 = Jul-Sep, Q4 = Oct-Dec) -> kwh_q1, kwh_q2, kwh_q3, kwh_q4.
  metric_keys: kwh_q1, kwh_q2, kwh_q3, kwh_q4
- q4: Half-year change (percentage change): total energy_kwh for January-June -> kwh_h1; July-December -> kwh_h2; (kwh_h2 - kwh_h1) / kwh_h1 * 100 -> kwh_h2_vs_h1_change_pct (in percent).
  metric_keys: kwh_h1, kwh_h2, kwh_h2_vs_h1_change_pct
- q5: Hot-day commercial load (conditional filtering): readings with building_type Commercial and a non-missing temperature_c >= 25: their number -> hot_commercial_reading_count; their mean energy_kwh -> hot_commercial_mean_kwh.
  metric_keys: hot_commercial_reading_count, hot_commercial_mean_kwh
- q6: Distribution summary (statistical summary): median and sample standard deviation (denominator n - 1) of energy_kwh over all readings -> kwh_median, kwh_std; mean temperature_c over readings with a non-missing temperature -> temperature_mean; number of readings with missing temperature_c -> temperature_missing_count; Pearson correlation between temperature_c and energy_kwh over Commercial readings with a non-missing temperature -> commercial_temp_kwh_corr.
  metric_keys: kwh_median, kwh_std, temperature_mean, temperature_missing_count, commercial_temp_kwh_corr
- q7: Tariff and meter usage (derived step): total energy_kwh for peak and off-peak tariffs -> kwh_peak, kwh_off_peak; kwh_peak / total_kwh * 100 -> peak_kwh_share_pct; number of distinct meter_id values -> unique_meter_count; largest total energy_kwh for any single meter_id -> highest_use_meter_kwh.
  metric_keys: kwh_peak, kwh_off_peak, peak_kwh_share_pct, unique_meter_count, highest_use_meter_kwh

All required metric_keys: total_kwh, reading_count, mean_kwh_per_reading, kwh_residential, kwh_commercial, kwh_industrial, kwh_q1, kwh_q2, kwh_q3, kwh_q4, kwh_h1, kwh_h2, kwh_h2_vs_h1_change_pct, hot_commercial_reading_count, hot_commercial_mean_kwh, kwh_median, kwh_std, temperature_mean, temperature_missing_count, commercial_temp_kwh_corr, kwh_peak, kwh_off_peak, peak_kwh_share_pct, unique_meter_count, highest_use_meter_kwh
