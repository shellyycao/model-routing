The task is clear: write a Python script that reads cleaned.csv from INPUT_DIR, computes the metrics, and writes findings.json to OUTPUT_DIR as a flat JSON object with all metric keys mapping to finite numbers.

Key considerations:
- churn_rate values as percentages (multiply by 100)
- sample std with ddof=1
- satisfaction_score nullable - skip NaN for mean, count missing
- cohort by signup year
- at-risk: support_tickets >= 5 AND satisfaction_score <= 2 (non-missing)
- LTV means by plan
- relative percentage changes
- No rounding, full precision
- Ensure finite numbers (handle potential division by zero defensively, but data should be fine)
- Convert numpy types to native Python floats/ints for JSON serialization

Let me write the script carefully.

```python
import json
import os

import numpy as np
import pandas as pd

INPUT_PATH = os.path.join(os.environ["INPUT_DIR"], "cleaned.csv")
OUTPUT_PATH = os.path.join(os.environ["OUTPUT_DIR"], "findings.json")


def to_finite_number(value):
    v = float(value)
    if not np.isfinite(v):
        return 0.0
    return v


df = pd.read_csv(INPUT_PATH, parse_dates=["signup_date"])

findings = {}

# q1
findings["customer_count"] = float(len(df))
findings["churn_rate_pct"] = float(df["churned"].mean() * 100)
findings["avg_monthly_fee"] = float(df["monthly_fee"].mean())

# q2
for plan, key in [("Basic", "churn_rate_basic_pct"), ("Standard", "churn_rate_standard_pct"), ("Premium", "churn_rate_premium_pct")]:
    subset = df[df["plan"] == plan]
    findings[key] = float(subset["churned"].mean() * 100)

# q3
years = df["signup_date"].dt.year
for year in [2021, 2022, 2023, 2024]:
    subset = df[years == year]
    findings[f"churn_rate_cohort_{year}_pct"] = float(subset["churned"].mean() * 100)

# q4
monthly = df[df["contract_type"] == "Monthly"]
annual = df[df["contract_type"] == "Annual"]
monthly_rate = monthly["churned"].mean() * 100
annual_rate = annual["churned"].mean() * 100
findings["churn_rate_monthly_pct"] = float(monthly_rate)
findings["churn_rate_annual_pct"] = float(annual_rate)
findings["churn_monthly_vs_annual_change_pct"] = float((monthly_rate - annual_rate) / annual_rate * 100)

# q5
at_risk = df[(df["support_tickets"] >= 5) & (df["satisfaction_score"].notna()) & (df["satisfaction_score"] <= 2)]
findings["at_risk_customer_count"] = float(len(at_risk))
findings["at_risk_churn_rate_pct"] = float(at_risk["churned"].mean() * 100)

# q6
findings["tenure_mean"] = float(df["tenure_months"].mean())
findings["tenure_median"] = float(df["tenure_months"].median())
findings["tenure_std"] = float(df["tenure_months"].std(ddof=1))
findings["satisfaction_mean"] = float(df["satisfaction_score"].mean())  # skips NaN
findings["satisfaction_missing_count"] = float(df["satisfaction_score"].isna().sum())

# q7
ltv = df.groupby("plan")["lifetime_value"].mean()
ltv_basic = float(ltv["Basic"])
ltv_standard = float(ltv["Standard"])
ltv_premium = float(ltv["Premium"])
findings["ltv_basic"] = ltv_basic
findings["ltv_standard"] = ltv_standard
findings["ltv_premium"] = ltv_premium
findings["premium_vs_basic_ltv_change_pct"] = float((ltv_premium - ltv_basic) / ltv_basic * 100)

# ensure all values are finite native floats
clean = {k: to_finite_number(v) for k, v in findings.items()}

with open(OUTPUT_PATH, "w") as f:
    json.dump(clean, f, indent=2)
```

Note about at_risk with empty subset: mean of empty would be NaN — handled by to_finite_number fallback to 0.0. But likely not empty. Should customer_count be an integer? The spec says single finite number; float is fine. Could write int for counts, but float works with json. Actually, writing int is also a number. To be safe, floats are fine.

One thing: json.dump with float('inf') would produce Infinity, which is invalid — the to_finite_number handles that. Division by zero: annual_rate could be zero in theory; the fallback handles it.
