You are the data-cleaning stage of a three-stage data workflow (cleaning -> analysis -> reporting).
Write ONE self-contained Python 3 script that cleans the raw data exactly as specified below.

## Original objective
Clean and join a support-ticket export with an agent roster, analyse cost, speed, reopening, satisfaction and agent concentration, then report verified findings.

## Input/output contract (mandatory)
- Your script runs in an isolated sandbox with NO network access. Available libraries: the Python
  standard library, pandas and numpy.
- Read input files ONLY from the directory given by the environment variable INPUT_DIR, e.g.
  os.path.join(os.environ["INPUT_DIR"], "<name>"). Available input files: "tickets.csv", "agents.csv".
- Write every output file to the directory given by the environment variable OUTPUT_DIR. Write nowhere else.
- Write the cleaned CSV to os.path.join(os.environ["OUTPUT_DIR"], "cleaned.csv") and set
  `output_filename` to "cleaned.csv".
- Also write os.path.join(os.environ["OUTPUT_DIR"], "cleaning_summary.json"): a JSON object with at least
  "raw_rows" (rows read) and "cleaned_rows" (rows written), plus any per-rule counts you track.
- The script takes no command-line arguments and must not print large amounts of data.

## Cleaning requirements (apply all of them, in order)
R1. Read both tickets.csv and agents.csv as text. Strip whitespace. Treat empty, NA, N/A, null, None and - as missing.
R2. In tickets.csv, remove duplicate ticket_id rows before any filtering; keep the first in raw-file order.
R3. In agents.csv, normalise agent_id to upper case and remove duplicate agent_id rows, keeping the first.
R4. Agent roster: map team case-insensitively from Alpha/Team Alpha, Beta/Team Beta, Gamma/Team Gamma; map region East/E and West/W; parse hourly_cost after removing $, USD and commas. Exclude roster rows with an invalid field or cost <= 0.
R5. Tickets: normalise agent_id to upper case. Join to the cleaned agent roster by agent_id and drop tickets without a matching agent.
R6. Map channel case-insensitively: Email/E-mail -> email, Chat/Live Chat -> chat, Phone/Call -> phone. Drop invalid channels.
R7. resolution_minutes: remove a trailing 'min' or 'minutes', parse a whole number from 1 through 480, and drop invalid rows.
R8. satisfaction_score: parse a whole number from 1 through 5. Invalid or missing values become an empty cell and the row is kept.
R9. reopened: map Yes/Y/True/1 to 1 and No/N/False/0 to 0, case-insensitively. Drop invalid or missing values.
R10. Add labor_cost = resolution_minutes / 60 * hourly_cost, rounded to 2 decimals.
R11. Output exactly: ticket_id, agent_id, team, region, channel, resolution_minutes, satisfaction_score, reopened, hourly_cost, labor_cost. Sort by ticket_id and write CSV without an index.

## Required schema of the cleaned CSV (columns in this order)
- ticket_id: str; not nullable
- agent_id: str; not nullable
- team: category; not nullable; allowed values: 'Alpha', 'Beta', 'Gamma'
- region: category; not nullable; allowed values: 'East', 'West'
- channel: category; not nullable; allowed values: 'email', 'chat', 'phone'
- resolution_minutes: int; not nullable; min 1; max 480
- satisfaction_score: int; nullable; min 1; max 5
- reopened: int; not nullable; min 0; max 1
- hourly_cost: float; not nullable; min 0.01
- labor_cost: float; not nullable; min 0
