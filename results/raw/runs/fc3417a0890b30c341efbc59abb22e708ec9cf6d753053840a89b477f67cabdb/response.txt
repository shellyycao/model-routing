**Issues found:**

1. **Missing referenced nodes**: `nodes = set(deps)` only includes keys, but nodes referenced as dependencies (values) that aren't keys should also be included.

2. **`incoming` dict only covers `nodes`**: Since nodes doesn't include referenced-only nodes, `incoming` misses them.

3. **Cycle detection**: No `ValueError` is raised when a cycle exists.

4. **`m not in ready` check**: This is O(n) on a list but more importantly, `ready` is a heap (list), so this check works but is inefficient. However, the real bug is that after we add all nodes (including referenced ones), the logic needs to handle them properly.

Let me trace through `{'b':['a'],'a':[]}`:
- `nodes = {'b', 'a'}` ✓
- `incoming = {'b': {'a'}, 'a': set()}` ✓
- `ready = ['a']` ✓
- Pop 'a', out=['a'], check m in nodes: for 'b', remove 'a' from incoming['b'] → incoming['b']=set(), push 'b'
- Pop 'b', out=['a','b'] ✓

This actually passes the visible check. But consider `{'b':['a']}` — 'a' is not in nodes, so `incoming` doesn't have 'a', and 'a' never gets added to ready.

**Fixes:**
1. Collect all nodes (keys + all referenced values)
2. Add cycle detection (if `len(out) < len(nodes)` after loop, raise ValueError)
